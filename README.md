# CS-03 Phishing Awareness Kit

## Cybersecurity Awareness & Controlled Phishing Simulation

A cybersecurity awareness training kit designed to help employees recognize, avoid, and report phishing attempts through practical training, a controlled simulation, and user assessment.

> Developed as part of a 3MTT Cybersecurity Capstone Project.

---

## 🎯 Project Overview

Phishing and social engineering remain major cybersecurity risks because attackers often target human behavior rather than technical vulnerabilities.

This project addresses that problem by combining:

- Phishing awareness training
- A controlled phishing simulation
- Identification of phishing red flags
- Interactive user assessment
- Reporting guidance
- Technical network analysis
- Security metrics
- Remediation recommendations

All simulations were conducted in a controlled and authorized laboratory environment using fictional scenarios.

## 🔬 Technical Activities

### Network Reconnaissance

Nmap was used within the controlled laboratory environment to perform basic service discovery and identify exposed services.

### DNS Traffic Analysis

Wireshark was used to capture and analyze DNS traffic and understand how network requests can be observed during security testing.

---

## 🧠 Phishing Awareness

The training kit teaches users how to identify common phishing indicators, including:

- Suspicious senders
- Unexpected requests
- Urgent or threatening language
- Suspicious links
- Fake login pages
- Requests for sensitive information
- Unusual attachments

---

## 🧪 Controlled Simulation

The project includes a safe, fictional phishing simulation designed for awareness training.

The simulation does **not** target real users or collect real credentials.

---

## 📊 User Assessment

Users complete a short quiz to evaluate their understanding of phishing indicators and appropriate responses.

The recommended response workflow is:

**STOP → CHECK → VERIFY → REPORT**

---

## 🛡️ Security Recommendations

The project recommends measures such as:

- Security awareness training
- Multi-factor authentication
- Email filtering
- Strong password practices
- Incident reporting procedures
- Regular phishing-awareness exercises
- Monitoring and review of security metrics
